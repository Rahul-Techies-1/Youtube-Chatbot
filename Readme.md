# 🎥 YouTube RAG Chatbot

An AI-powered YouTube Question Answering application built using LangChain, ChromaDB, Hugging Face, and Streamlit.

## 🚀 Features

- Ask questions from any YouTube video
- Automatic transcript extraction
- Vector Search using ChromaDB
- Hugging Face Embeddings
- Qwen LLM for Answer Generation
- Source Chunks Display
- Professional Streamlit UI

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- ChromaDB
- HuggingFace
- Qwen 2.5
- YouTube Transcript API
